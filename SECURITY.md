# Security Policy

## Reporting a Vulnerability

Do not report security vulnerabilities in public GitHub Issues.

Use GitHub's private vulnerability reporting flow when it is available for this repository:

https://github.com/Lachi90/MacStorageAtlas/security/advisories/new

If private vulnerability reporting is unavailable, open a minimal public issue that says a private security contact is needed, without including exploit details, private paths, logs, screenshots, or proof-of-concept material.

## Scope

Security reports should focus on vulnerabilities in MacStorageAtlas itself, including unsafe file operations, permission handling issues, unintended data exposure, or packaging/signing problems.
