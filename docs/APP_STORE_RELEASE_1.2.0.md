## What's New in This Version

```text
• See what is on your Mac and what is only in the cloud. Files from iCloud Drive, OneDrive, or Dropbox that are not downloaded get a cloud icon in the folder tree and in Largest files. Hover the icon to see how much of a folder lives only in the cloud. Nothing is downloaded.
• Rescan a single folder. Right-click a folder or press Shift-Command-R to remeasure just that folder while the rest of the result stays as it is.
• Context menus. Right-click any item for Quick Look, Reveal in Finder, Copy Path, the cleanup basket, and Move to Trash.
• A full menu bar with keyboard shortcuts, including Command-R to rescan and Command-Period to stop.
• Largest files and File types now follow the folder you select.
• A tidier toolbar: one Scan / Rescan / Stop button and direct icon buttons for item actions.
• Improved VoiceOver support for every button in the main window.
```
