MacStorageAtlas

Privacy Policy

Last updated: August 19, 2026

MacStorageAtlas does not collect, sell, share, or upload personal data.

The app is a local macOS disk space analyzer. Scan results, file paths, and optional history snapshots stay on your Mac unless you choose to export or share them yourself.

Data Collection

MacStorageAtlas does not operate a user account system, analytics service, advertising network, tracking SDK, telemetry service, or remote backend.

The app does not transmit scanned file names, paths, file metadata, file contents, scan results, duplicate-analysis results, cleanup selections, or history snapshots to Lachmann Thiem Software GbR or to any third party.

Local Processing

When you scan a folder or volume, MacStorageAtlas reads local file-system metadata such as paths, sizes, dates, file types, and access errors so it can show disk-usage results. Duplicate analysis may read local file contents only to confirm exact byte-for-byte matches.

Cleanup actions are performed locally through macOS features such as Finder, Quick Look, Trash, and file-system copy or move operations.

Local Storage

If you enable scan history, MacStorageAtlas may store scan snapshots locally in your user account. These snapshots are controlled by you and can be deleted from inside the app or by removing the local files.

If you export CSV or JSON results, the exported files are created only at the location you choose.

Permissions

macOS may ask you to grant file or Full Disk Access permissions so MacStorageAtlas can scan protected locations. These permissions are managed by macOS in System Settings. Granting access does not cause MacStorageAtlas to upload data.

Third-Party Services

The Mac App Store may process purchase, download, crash, and usage information according to Apple's privacy policies. GitHub may process information when you visit the project website, repository, releases, or issue tracker.
