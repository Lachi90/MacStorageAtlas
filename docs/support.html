Support

Last updated: August 20, 2026

Use GitHub Issues for reproducible bugs and feature requests.

Please do not post private file paths, screenshots with personal data, account details, billing information, or security vulnerabilities in public issues.

Open a GitHub issue View existing issues

Before Opening an Issue

  • Check whether the issue already exists.
  • Try the latest GitHub release or Mac App Store version.
  • Restart the app and repeat the smallest scan that reproduces the problem.
  • Remove or anonymize private folder names and personal file paths before posting.

What to Include

  • MacStorageAtlas version.
  • macOS version.
  • Mac model and whether it is Apple Silicon or Intel.
  • Whether the app came from GitHub Releases or the Mac App Store.
  • Steps to reproduce the problem.
  • What you expected to happen and what actually happened.

Privacy

MacStorageAtlas scans local file-system metadata. Support requests should describe behavior without exposing private file names, personal paths, document contents, or screenshots that reveal sensitive information.

For more detail, read the Privacy Policy.

Security Vulnerabilities

Do not open a public issue for a vulnerability. Use GitHub's private vulnerability reporting flow or follow the repository security policy.
